# SegmentacaoRadiografiasBitewing
A cárie dentária é uma lesão bacteriana progressiva que destrói os tecidos do dente, exigindo detecção precoce para evitar tratamentos invasivos, nossa solução atua aí, um Sistema de Auxílio ao Diagnóstico em Radiografias Bitewing. O pipeline se dá com YOLO para extrair os dentes e Redes Neurais para realizar a segmentação semântica das lesões.
